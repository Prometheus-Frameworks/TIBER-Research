2. **Retain both originals.** Each author saves v1 before inspecting the other's picks where feasible; record actual exposure. Include author, original clock/cutoff or explicit unknowns, salary source and rationale. Use one coherent external projection snapshot if comparing numerical totals; unavailable forecasts remain unavailable.
3. **Make handoff receipt explicit.** For each stage retain sender/poster, intended next participant, exact input links, actual posted time, acknowledged receipt when available, output locator and ready/partial/blocked status. Unknown delivery stays unknown; no confirmation invented.
