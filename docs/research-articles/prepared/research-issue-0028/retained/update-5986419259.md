## Identity coverage clocks and rights

Every later observation must bind dataset, era/channel, exact source revision and definition; raw-byte digest and byte count; retained locator; season/type/game/week/event team/opponent; canonical and native identities with resolution status; metric-specific numerator, denominator and units; eligible, covered, excluded, unknown and unmatched counts; purpose receipt; and correction/finality state.

**Joins.** PBP begins with exact native game/play identity and offense. FTN uses `nflverse_game_id` + `nflverse_play_id`; participation uses its native game/play keys. Confirm uniqueness, drive context where required, season/week and reciprocal teams before a join. A candidate key is not presumed unique. Duplicate/conflicting keys block aggregation; unmatched rows remain visible rather than disappearing through an inner join. Preserve raw LA/WAS/etc. alongside an evidenced canonical alias map. Never use player names, a current team, or fuzzy matches to repair identity. H2 includes all credited targets, including OTHER and unresolved recipients, in the team denominator; unresolved position can prevent an exact RB-room total even if team arithmetic reconciles.

## Proposed deterministic metric definitions

These are frozen design choices for later review, not current contract amendments. Each output carries a definition version and source predicates. Unknown eligibility cannot become false. No rounding before aggregation; display rounding occurs once and raw sums/counts stay inspectable.

**Common event universe.** One exact REG season/window, one retained revision per game, source-credited competitive offensive events. Exclude deleted/no-play rows, two-point attempts, kneels and spikes. Do not exclude every penalty: retain an event only when its statistical credit stands; unresolved credit/aborted/lateral handling blocks complete-universe qualification. Missing required predicate flags produce eligibility_unknown. All raw rows remain available for exclusions and reconciliation.

**Rushing universe R.** Require `rush_attempt=1`, confirmed non-kneel and non-scramble, and standing rush credit. Include designed QB rushes, including sneaks, in primary team rushing environment. A RB-only restriction is a separately labeled sensitivity with resolved position. Sneak-excluded sensitivity requires a qualified sneak classifier; do not infer from down/distance or require FTN to run primary R. Do not substitute the existing builder's dropback-based run split for R.

| Metric | Exact proposed numerator and denominator | Missingness and interpretation |
| --- | --- | --- |
| Stuff rate | Count of R events with finite yards_gained <= 0 / count of R events with finite yards_gained | Also expose all-R count and yardage-covered/all-R. Incomplete yardage yields covered-only status, not a complete-R rate |
| Rush success | Count of R events with finite EPA > 0 / count of R events with finite EPA | EPA = 0 is not success. Record excluded/missing EPA; never use overall successRate |
| Rush EPA per play | Sum of finite EPA over R / identical valid-EPA R count | Negative EPA preserved; zero denominator unavailable |
| Direction/gap | For each exact source category and explicit unknown category, retain R count; success/EPA operands use that category's covered subset | Keep direction/gap separately and joint only if validated. Category totals including unknown must reconcile to R |
| Box distribution | Count of joined R events in each observed defender-count category / charted R count | Unknown category count and charted/all-R coverage separate; missing is not light box. No heavy-box threshold unless versioned separately |
| NGS RYOE per covered attempt | Sum of source RYOE totals / sum of matching source covered rush_attempts | Validate total/rate consistency at source precision. Weight player rates only by proven covered attempts. Never divide by all PBP carries |

**Dropback universe D.** Require `qb_dropback=1` within the common universe. Include throws, sacks and scrambles; exclude spikes. Validate event-class consistency against the actual revision. Source `pass_attempt` includes sacks, so never add sacks again to that count. D is not team box-score attempts, and box attempts plus sacks do not establish D without scramble and special-play reconciliation.

| Metric | Exact proposed definition | Missingness and interpretation |
| --- | --- | --- |
| Sack rate | Count of D with sack=1 / D with known sack flag | Expose covered/all-D; sack count is also retained. Missing sack flags are unknown |
| QB-hit rate | Count of D with qb_hit=1 / D with known hit flag | Preserve overlap with sacks; no “pressure rate” relabel |
| Sack-or-hit sensitivity | Count with at least one known positive / D with sufficient flags to decide union | A positive flag establishes union even if other flag missing; zero requires both known false. Never sum overlapping counts |
| QB-fault sack sensitivity | Raw sack count, fault=true/false/unknown sack counts; classified non-QB-fault sacks / same raw sack-covered D denominator | Unknown sacks stay unresolved. Optional classified-only ratio excludes unknown-classification sacks from denominator and labels selection; neither view identifies OL-caused sacks |
| Blitzers and pass rushers | Separate mean counts: sum finite n_blitzers / covered D; sum finite n_pass_rushers / its own covered D | Different coverage denominators remain separate; counts are not pressure flags |
| NGS time to throw | Retain passer source average; multi-passer/window average only as sum(avg × exact throw-covered count) / sum(count) | Source excludes sacks. If source attempts do not demonstrably equal covered throws, do not aggregate. Not time to pressure or all-dropback protection |

First-contact, yards-before-contact, per-lineman grades, fixed line shares and a composite OL score are excluded. The existing rbContext 65% estimate and random/estimated OLC values are not observations; #28 explicitly prohibits their reuse. A narrow code search did not validate that legacy estimate's exact current file path, so no runtime-path claim is made.

## Hypothesis design and falsification

No hypotheses were run. Proposed windows, sample rules and controls below need approval and power assessment before execution; they do not establish adequate sample size or predictive usefulness.

**Common design.** Analyze one compatible season/channel at a time. Candidate retrospective season: 2025 REG only if exact retained operands and Research purpose qualify; do not fall back to 2024 silently. Unit is team-game for team measures, player-game for individual outcomes. Primary feature window is the team's three prior played games, excluding byes; outcome is its next played game. Features and labels never overlap. Preserve personnel/QB/runner, play-calling, game-state, opponent and sample confounding.

Proposed exploratory eligibility floors: three feature games; at least 40 eligible feature rushes for rushing measures or 60 feature dropbacks for protection; complete required predicates and explicit covered fractions. These are design defaults, not admitted minimum-sample rules. Covered-only sensitivity requires at least 90% field coverage, always labeled; full-universe claims require complete coverage. Do not relax missingness thresholds after inspecting results.

| Hypothesis | Endpoint and baseline | Controls and failure criteria |
| --- | --- | --- |
| H1 prior environment and later RB outcome | Primary: subsequent RB rushing yards per credited carry; secondary: next-game carries. Compare association beyond lagged player outcome/usage and team rush volume | Bind RB identity at event time. Efficiency needs >=5 next-game carries and reports how that selection changes cohort; opportunity endpoint keeps observed zeros. Control QB, runner, opponent, home/away, prior game-state distribution. Null/unstable/opposite association, or disappearance after runner/baseline controls, challenges usefulness |
| H2 prior protection and later RB targets | Primary team-RB credited target share: sum qualified RB targets / all credited team targets; secondary individual RB share. Baseline is prior target share and team target volume | Outcome denominator >0; proposed >=10 team credited targets for stable sensitivity only. Preserve all-position/unresolved totals. Control QB, personnel availability, prior pass volume and game-state. No checkdown-causality inference from target share |
| H3 prior protection and later RB routes | Primary RB routes / matching team D; secondary blocking/chip responsibility on compatible events | **Blocked** until true routes and role observations qualify. Not run on primary-receiver labels or participation proxies. Increased targets/route can coexist with reduced routes; H2 cannot resolve H3 |

For each hypothesis preregister the permitted cohort, outcome revision, missingness/exclusion census, expected sign, controls, baseline and estimator before any result calculation. If essential controls are unavailable, downgrade to a bounded descriptive pilot and explicitly change the question before running; do not label uncontrolled association predictive or causal.

**Raw and opponent-adjusted views.** Retain raw operands first. Proposed retrospective adjustment uses the opponent's other games only, never the evaluated game, with the same metric definition and era. Require at least three other eligible games and matching sample floors. An explicitly retrospective leave-game-out baseline may contain later-season games and must never enter a prediction. Initial adjustment can be a raw-minus-opponent-baseline residual; keep rate differences in percentage points and EPA differences in EPA/play. Do not invent league-average fills. Shrinkage is deferred from the first slice; any later regularization requires its own formula, weight/sample and uncertainty design. Upcoming schedule is a separate future-context object.

**Uncertainty and multiplicity.** Report effect sizes and 95% intervals with team-clustered resampling, preserving game dependence; flag sparse clusters. Freeze one primary exposure per hypothesis before execution; mark other metrics/sensitivities exploratory. Apply Holm adjustment across executable primary hypotheses, never count blocked H3 as an observed null. Report missingness by team/week/position and compare included/excluded populations descriptively. Negative controls use non-overlapping lag windows and a synthetic future-feature rejection test. A null interval, fragile sign, selection-dependent result, no improvement over baseline, or materially uncontrolled confounding is a legitimate stop result.

No numeric “material effect” threshold is claimed here: power and smallest useful effect must be set in the later preregistration once exact qualified population and intended use are known. Strict PIT evaluation remains separately blocked by #190, regardless of any retrospective association.
