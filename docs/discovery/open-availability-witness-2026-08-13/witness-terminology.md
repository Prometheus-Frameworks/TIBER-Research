# Witness terminology (proposed discovery glossary)

Status: **AUTHORITY-INERT GLOSSARY — NOT AN OPERATOR ADOPTION RECORD**

This file records useful wording proposed during the 2026-08-13 discovery
work. No durable issue comment, authority snapshot, or digest-bound operator
quote was found adopting this glossary or reserving an acronym. Current
schemas and adopted contracts control wherever they are more specific. The
authority and custody boundary in [`README.md`](README.md) also applies.

**Witness** — an identified source of observations about the external
football world that TIBER can inspect and potentially admit. A witness is
not automatically truth.

**Missing Witness** — following the current Agent Entry contract, a specific
observation that would materially resolve a node or edge but is unavailable
to the run. It must name what it would resolve and why it cannot be obtained;
it is never an invitation to substitute a proxy.

**Manual Witness** — the current Research precedent is an operator-directed,
per-instance observation mode; it is not defined by whether a human or an agent
performs the read. Manual acquisition alone grants no admission or authority. A
record is usable only when a separately governed contract supplies exact source
identity, true retrieval/admissibility clocks, a per-instance receipt,
retention/reportability scope, and operator authority. This glossary does not
extend that precedent.

**Witness Restoration** — provisional shorthand for researching whether a
Missing Witness could be recovered through a qualified source or a separately
authorized observation process. The term authorizes nothing.
