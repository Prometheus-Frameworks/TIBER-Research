The pilot report did not identify that page's URL. The separate research trace showed the [NFL Pro player page](https://pro.nfl.com/players/player/55886) returning “API Refresh Failed. Try to reload.” before the cutoff; exact per-source retrieval time and publisher bytes were not retained, and current behavior may differ. It retained the unavailable under-center play count as a limitation rather than inventing a denominator.

For a retrospective exercise, the input is this recorded failure and response. Do not assume an API failure still occurs, or that today's successful fetch proves what the page displayed before the original cutoff. No publisher-page bytes or contemporaneous archive are included in this snapshot.
